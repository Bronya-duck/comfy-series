# Comfy Series 第一版验收

2026-10-07，在本机 ComfyUI **0.3.64**、torch **2.8.0+cu129**、RTX 5070 Laptop **8151 MiB 显存**上完成实现与实际生图。工具使用独立 Python **3.12.14**。本报告区分实际 GPU 运行、图像检查和故障模拟，未通过的结果继续保留原状态。

## 交付内容

- 项目技能 `.agents/skills/comfy-series`，配套 Python CLI、锁定依赖、初始化与启动脚本。
- TXT/Markdown、图片、网址、PDF 页面预览与 DOCX 文本/嵌入图片导入；请求保存素材编号、来源及哈希。
- SQLite 风格/系列/资源/任务档案，加每轮可读 JSON、实际参数、模型清单和 UI/API 工作流。
- SDXL 文生图、基础图生图、IPAdapter 风格参考、模型放大、精确最终尺寸。
- 累计30GB预算、固定提交与SHA校验、断点续传、候选替代、确认清单删除、最多三轮与未知任务恢复。
- [本地资料库与图库](http://127.0.0.1:8191/)，仅监听本机，只读。

## 风格参考的真实状态

IPAdapter 源码固定为 `a0f451a5113cf9becb0847b92884cb10cbdec0ef`。H94 权重固定为 `018e402774aeeddd60609b4ecdb7e298259dc729`，下载 **3,375,890,960 字节**，两文件都与上游 SHA-256 匹配。首次网络失败后，通过明确代理恢复，来源和完成记录保存在 `data/reference_assets.json`、`data/reference_installation.json`及下载账本。

## 工作流与浏览验证

原生 SDXL 画布和带 IPAdapter 的画布均通过 ComfyUI 的“文件 → 打开”实际导入，并点击“运行”再次成功输出 **1536×1024**。前端编译后的输入与原 API JSON 一致。原生路线在本机此环境下重跑的像素也完全相同；不推广为跨硬件保证。证据分别在 `data/acceptance/ui-replay.json`和`ui-reference-replay.json`。

所有已生成轮次的画布转换回 API 后与保存的 API 图一致。本机可复用模板在 `comfy_series/templates`，资料库另缓存4份实际运行的本地派生工作流。40个原始来源、10份上游精选缓存均保留架构、依赖、许可、固定版本、查询时间和验证状态。上游模板可能缺少模型、前端辅助节点或所需自定义节点；这些保持待验证及具体原因。

资料页已实际在浏览器打开检查；图片、来源网址、工作流和复现记录可查看。全部任务表包括未出图的失败记录。文件路由限定素材、档案、工作流与生成目录，不提供权重和 SQLite 文件；页面无写入接口。

## 工具与故障验证

**26项自动化测试全部通过**。测试使用临时文件、本地 HTTP 服务和故障模拟，不删除真实权重，也不声称真实显存耗尽已被诱发。

- 检查精确尺寸、比例矛盾、输入类型、节点连线/类型/环路、画布/API互转、参考模式版本约束。
- 验证风格版本不可静默更换、系列预算复用、正式切换需用户选择和对应删除清单。
- 模拟下载中断并恢复 Range，服务器忽略 Range 时重新下载，403候选跳过、哈希失败不登记、预算耗尽改用已有候选。
- 验证未经确认不删除、清单后文件变化会拒绝删除、路径越界被拒绝、删除不重置累计预算。
- 验证 PDF 扫描页的视觉回退、文本/网页/DOCX来源与嵌图提取、图库转义和文件边界。
- 模拟持续 OOM 时三轮停止，保留错误；等待超时恢复原 prompt，提交回执丢失与历史读取断线均不重复提交。
- 视觉检查有失败/部分通过项时不能接受；较差重试保留较好结果。

原始输出在 `data/acceptance/tool-tests.txt`及结构化结果 `tool-tests.json`。HF模型搜索、固定文件规格、权重下载和哈希比对也已在真实网络环境运行。技能校验脚本通过；CLI参数错误返回JSON。

另有持久化输入验收：Markdown、无文本层的扫描PDF、DOCX文本与图片，以及实际读取的官方SDXL示例网址。扫描页预览和DOCX图片均实际查看，形成带素材编号、来源和SHA的制作摘要；样本明确标记为验收资料。记录在 `data/acceptance/material-inputs.json`，可在资料页查看原件与提取内容。

资料页实际HTTP检查16项通过，包括工作流与图片访问、PDF预览、DOCX图片、受限文件边界、禁用写入，以及拒绝第二个端口实例。旧实例已关闭，当前页面与最新版渲染一致；记录在 `data/acceptance/browser-http.json`。不明来源的下载断点会先拒绝拼接，不占用新候选的预算预留。

## 保留的限制与恢复方式

预装的 `WAI_NSFW-illustrious-SDXL_v14.safetensors` 文件头无效，第一次运行实际失败。原文件保留，工具会在加载前拒绝它；新版本 S002-v2 改用已有可读取的 Pony SDXL。两个失败任务仍在资料页与档案中。

既有主模型的精确上游身份与许可尚未完整核实，元数据保留缺口；新增权重来源已核实。CivitAI匿名下载本次未验证，受限时使用HF、维护者来源或本机候选。当前未新增独立 LLM API；自由选择和视觉判断由 Codex 完成。

需要恢复原 ComfyUI 配置时，结束本项目启动的空闲服务，使用原 `comfy_workflow/start_comfyui.ps1`。项目没有修改 ComfyUI 的 Python 环境。真正删除旧权重只在用户确认具体清单后执行。角色一致性、复杂局部修复、视频、训练及更大尺寸分块输出仍属后续扩展。
