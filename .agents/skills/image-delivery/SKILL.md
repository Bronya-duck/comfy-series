# 图片交付助手

把已完成的图片交付到使用它的项目。处理文件名称、目录、来源记录和检索；图片内容、像素尺寸及格式保持原样。

## 每次交付的交互

先确定图片来源，运行 `inspect`。Comfy Series 传本次 `job.json`，默认选取验收通过的版本；通用图片传明确的本地路径列表。实际文件缺失、记录矛盾或无通过结果时说明问题，保留原任务状态。

每次交付都向用户展示下列模板并等待**本次答复**，即使之前已给出名称或路径也一样；已有信息可以预填。一次收集整批要求，不在生成重试的每一轮询问：

```text
目标文件夹：完整绝对路径
文件名：单张填写名称；多张填写名称列表或统一前缀
用途：可选，例如游戏背景、封面、按钮素材
```

展示通过图片的顺序及数量，便于逐张填写名称。统一前缀不含扩展名，按顺序生成 `前缀_001`、`前缀_002`。当用户要求修改缺陷导致继续生图时，完成评审后重新进入本次交付。

## 复制与登记

读 [工具接口](references/tools.md)，把完整请求写入 JSON 文件，再通过本技能 `scripts/run.ps1` 调用工具。只有收到本次模板答复后才设置 `delivery_confirmed: true` 并执行 `deliver`。明确目标目录和命名规则后，可以创建目录并完成复制。

源图按字节复制，保持原件以及原生图记录。名称不含扩展名时补齐实际格式；扩展名冲突或非法名称交给用户修正。同名同内容复用，同名不同内容追加编号，返回最终实际名称。

工具在目标图片文件夹保存 `image-manifest.json`。交付结束展示目标图片或可点击路径，说明复制、复用、失败数量及清单位置。部分失败按实际状态报告，复制失败不触发生图重跑或修改评审。

处理 Comfy Series 图片时，读 [Comfy 适配](references/comfy-series.md)。这里的“自动衔接”由 Comfy Series 技能交付步骤触发；工具本身按请求运行。

## 后续找图

用户或项目需要使用已交付图片时，优先用 `find` 在指定项目内查询清单，按名称、用途、路径、任务或风格编号定位。使用返回的实际路径，并检查 `exists` 和 `integrity`。清单存在而图片丢失或被替换时如实报告；扫描范围为明确指定的项目目录。

## 运行环境

需要 Python 3.12 或更新版本及 Pillow。`run.ps1` 优先发现 Codex 共用环境，然后检查技能所在克隆目录的 `.venv`、用户级 Comfy Series 环境、Python Launcher 和系统 Python。也支持 `-PythonPath` 显式指定已有解释器。工具不需要 Comfy 服务运行。安装用户级入口运行本技能的 `install.ps1`；它保留有冲突的入口并报告问题。需要建立或恢复 Comfy 自动衔接时，运行 `scripts/connect_comfy.ps1`，同时更新原安装源和当前使用副本；既有衔接会复用，其他说明保持原样。
